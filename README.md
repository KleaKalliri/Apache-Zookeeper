# Distributed Coordination with Apache ZooKeeper

A Java project exploring distributed coordination with Apache ZooKeeper, including distributed locking, queues, and producer–consumer interactions.

## Overview

This repository contains examples of coordination between processes in a distributed system. The project focuses on shared-resource access and communication through locking and queue-based mechanisms.

## Repository Contents

| File | Component |
|---|---|
| `DistributedLock.java` | Distributed lock component. |
| `DistributedLocking.java` | Distributed locking example. |
| `Queue.java` | Queue component. |
| `Producer.java` | Producer component. |
| `Consumer.java` | Consumer component. |
| `ZookeeperMonitor.java` | ZooKeeper monitoring component. |
| `Server1.java` | Server component. |
| `Helper.java` | Supporting utilities. |

## Topics Covered

- Distributed coordination
- Distributed locking
- Producer–consumer interactions
- Queue-based communication
- ZooKeeper monitoring

## Technologies

- Java
- Apache ZooKeeper

## Purpose

This project provides practical examples for studying coordination mechanisms in distributed systems using Java and Apache ZooKeeper.
